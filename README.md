# Evora Couture

Boutique en ligne moderne et élégante pour **Evora Couture**, dédiée à la présentation et à la vente de collections vestimentaires.

Site en ligne : https://evoracouture.netlify.app/

## Le problème

Les boutiques de mode ont besoin d'une présence digitale professionnelle pour présenter leurs collections, valoriser leurs produits et faciliter les achats en ligne.

## La solution

Evora Couture propose une expérience shopping digitale permettant aux clients de découvrir les collections et de consulter les différents produits.

1. Découverte de la boutique et de son univers.
2. Consultation des collections et des produits.
3. Présentation des détails et des prix.
4. Accès aux moyens de contact et de commande.

## Fonctionnalités

- Design moderne et élégant
- Présentation des collections
- Catalogue de produits
- Fiches produits détaillées
- Navigation intuitive
- Expérience responsive (mobile, tablette et ordinateur)
- Interface adaptée à l'univers de la mode

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS

## Installation

```bash
git clone https://github.com/lahcenmarishal/evora-couture.git
cd evora-couture
npm install
npm run dev
```
